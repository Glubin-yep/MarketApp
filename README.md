- Memory Leak

- Sometimes the market server is not pinged

- It's client-only, so you need to use the website if you want to do anything with your items

## Installation

1. 📥 Download the latest release from [GitHub Releases](https://github.com/Glubin-yep/MarketBot/releases)
2. 🛠 Launch the app and open the **Settings** tab
3. (Optional) If you want to receive notifications in Telegram:
   - Subscribe to [@MyMarketNotification_bot](https://t.me/MyMarketNotification_bot)
   - Find your Telegram ID via [@my_id_bot](https://t.me/my_id_bot)
   - Paste it in the **Settings** tab in the app
